# Learners Hub H5P Runtime

This service imports teacher-owned `.h5p` packages and renders them inside
Learners Hub lessons. It is intentionally isolated from the main school
application and has no public authoring or account interface.

## Security contract

- Package imports must carry the exact timestamped HMAC headers generated by
  Learners Hub.
- Learner player URLs require a signed grant that expires within ten minutes;
  the application currently issues five-minute grants.
- Player pages may be framed only by `LEARNERS_HUB_ORIGIN`.
- H5P content, libraries, and the activity map live on the `/data` volume.
- Content identifiers are UUIDs rather than sequential H5P identifiers.
- External network access from H5P activities is blocked by the player content
  security policy in the initial release.

## Required environment

| Variable | Purpose |
|---|---|
| `H5P_RUNTIME_SHARED_SECRET` | Shared HMAC secret, at least 32 random characters |
| `LEARNERS_HUB_ORIGIN` | Exact HTTPS origin allowed to embed the player |
| `H5P_DATA_DIR` | Persistent content directory; defaults to `/data` in Docker |
| `PORT` | Internal HTTP port; defaults to `8080` |

The root `deploy/hostinger` folder contains the production Compose and Caddy
configuration. The same secret and the resulting HTTPS runtime origin must be
added to the Learners Hub hosted environment as
`H5P_RUNTIME_SHARED_SECRET` and `H5P_RUNTIME_BASE_URL`.

## Local verification

```sh
npm ci
npm test
npm run typecheck
npm run build
```

`@lumieducation/h5p-express`, which are GPL-3.0-or-later. This service is
